# behavior-machines

Behavior trees with explicit halt semantics, for `no_std` + `alloc` targets.

A tree is ticked by the host. Each tick advances as far as the leaves allow,
and every leaf the tree abandons is halted exactly once, in the same call that
abandoned it. Leaves can therefore own real resources (tasks, tickets, locks)
and release them deterministically.

- **Typed leaves**: implement [`Leaf`] for your own type; an enum keeps the
  definition data-driven.
- **Typed context**: your context struct is the blackboard; there are no
  string keys.
- **Host-owned time**: the tree never reads a clock. The host passes [`Time`]
  to each tick, so tests and replays control time completely.
- **Pattern vocabulary**: node names and semantics follow the behavior-tree
  pattern.
  - Control: `Sequence`, `ReactiveSequence`, `Fallback`, `ReactiveFallback`,
    `Parallel` (success and failure thresholds), `IfThenElse`, `WhileDoElse`.
  - Decorators: `Inverter`, `ForceSuccess`, `ForceFailure`, `Timeout`,
    `Repeat`, `RetryUntilSuccessful`, `KeepRunningUntilFailure`.
  - Leaves: your own, plus `Sleep`, `AlwaysSuccess`, `AlwaysFailure`.
- **Deadlines**: `Tree::next_deadline` tells a sleeping host when a `Sleep` or
  `Timeout` needs the next tick.
- **No spinning**: looping decorators finish at most one child run per tick.
- **Observers**: `Tree::tick_observed` reports every node ticked or halted,
  by pre-order `NodeId`, for tracing and visualization.
- **state-machines leaves** (feature `state-machines`): `machine::InState`,
  `machine::Fire`, and `machine::WaitFor` drive any sync dynamic machine
  generated by `state_machine!`; `WaitFor` can send `cancel` when halted.

```rust
use behavior_machines::{Leaf, Node, Status, Time, Tree};

#[derive(Default)]
struct Robot {
    battery: u8,
    charging: bool,
}

enum Task {
    BatteryLow,
    Charge,
    Patrol,
}

impl Leaf<Robot> for Task {
    fn tick(&self, robot: &mut Robot, _now: Time) -> Status {
        match self {
            Self::BatteryLow if robot.battery < 20 => Status::Success,
            Self::BatteryLow => Status::Failure,
            Self::Charge if robot.battery == 100 => Status::Success,
            Self::Charge => {
                robot.charging = true;
                Status::Running
            }
            Self::Patrol => Status::Running,
        }
    }

    fn halt(&self, robot: &mut Robot) {
        if let Self::Charge = self {
            robot.charging = false;
        }
    }
}

let mut tree = Tree::new(Node::fallback([
    Node::sequence([Node::leaf(Task::BatteryLow), Node::leaf(Task::Charge)]),
    Node::leaf(Task::Patrol),
]))?;

let mut robot = Robot { battery: 10, ..Robot::default() };
assert_eq!(tree.tick(&mut robot, Time::ZERO), Status::Running);
assert!(robot.charging);

// Abandoning the tree halts the active `Charge` leaf exactly once.
tree.halt(&mut robot);
assert!(!robot.charging);
# Ok::<(), behavior_machines::BuildError>(())
```
